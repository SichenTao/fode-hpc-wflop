# T28 derived author data

These TSV files are lossless numeric extracts of `Northwind.xlsx` and
`data_scenarios.xlsx` from WINDFLOWER v1.0.0:

- paper DOI: `10.5194/wes-10-1661-2025`
- data DOI: `10.5281/zenodo.13946931`
- source: `https://github.com/Twitwi96/WINDFLOWER/tree/v1.0.0`
- revision: `427ee84dfdb9fb275b229e8eecf4503071d8fed4`
- upstream license: GNU Affero General Public License v3.0

`extraction_receipt.json` records the input and output SHA-256 identities.
The extractor is `scripts/prepare_core99_t28_data.py`. These files preserve
the original numeric observations and are not synthetic substitutes.
