# L0371 declared data proxy

This fixture supports the academic reproduction of Guo et al.,
DOI `10.1016/j.jweia.2021.104548`. It is not an author data release.

- `core99_l0371_proxy.bin` is deterministically generated by
  `scripts/prepare_core99_l0371_proxy.py`.
- Fixture SHA-256:
  `e327d31b787bdabdbdb5c820e452ca9d7f970be48cd183d245d009aa3d9ae58e`.
- Exact Horns Rev sector-wise Weibull scale, shape and frequency values come
  from Feng and Shen, DOI `10.3390/en8043075`, Table 1, which derives them
  from the same 1999–2002 mast record used by the target paper.
- The case-(c) 8/12/17 m/s stacks are digitized relative pixel lengths from
  target Fig. 3. Values hidden by cardinal grid lines are interpolated from
  adjacent direction bins and all weights are normalized.
- Vestas V80 power and thrust knots are digitized from Feng and Shen
  Fig. 1(b), because the target cites the curve but supplies no array.
- Horns Rev stability probabilities are digitized from target Fig. 11 and
  normalized separately within N/E/S/W, matching the target's stated
  missing-value normalization.
- Ideal and Horns stability `L,z0` pairs are exact target Tables 2 and 4.

The fixture is a versioned declared reconstruction. It must not be described
as the authors' original wind, turbine, stability, source-code, or random-state
asset.
